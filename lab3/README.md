# Лабораторная работа 3

В этой лабораторной работе создавались два пакета для использования в основной программе, производилась работа с массивами, срезами и строками.

## Пакеты

Эта лабораторная работа содержит два под-модуля (пакета): `mathutils` и `stringutils`.

[`mathutils`](./mathutils/mathutils.go) предоставляет функцию факториала `Factorial` (кэширующую, не рекурсивную).

[`stringutils`](./stringutils/stringutils.go) предоставляет функцию разворота строки `Reverse`.

## Задания

Были даны следующие задания:
1. Создать пакет mathutils с функцией для вычисления факториала числа.
2. Использовать созданный пакет для вычисления факториала введенного пользователем числа.
3. Создать пакет stringutils с функцией для переворота строки и использовать его в основной программе.
4. Написать программу, которая создает массив из 5 целых чисел, заполняет его значениями и выводит их на экран.
5. Создать срез из массива и выполнить операции добавления и удаления элементов.
6. Написать программу, которая создает срез из строк и находит самую длинную строку.

## Запуск

Для запуска нужно быть в директории модуля и выполнить команду:
```bash
go run .
```
