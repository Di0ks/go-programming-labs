# Пакет `utils`

Данный пакет содержит функции, которые часто используются в лабораторных, чтобы каждый раз не писать их заново.

## Экпортируемые функции

### `ReadLine`

Считывает все символы из стандартного ввода до тех пор, пока не встретится символ новой строки.
Полученная строка возвращается без учёта символа новой строки.

Паникует при ошибках ввода.

### `ReadSingleInt`

Считывает одно целое число из стандартного ввода и возвращает его.

Паникует при некорректном вводе пользователя (например, когда введено не число, а буква) или внутренних ошибках ввода.
