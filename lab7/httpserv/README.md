# Простой HTTP-сервер

В данном пакете представлена простая обёртка вокруг net/http.
Поддерживает конфигурация middleware, предоставления файла, директории, а также маршрутизацию.

`ServerConfig` это основная структура для задания конфигурации сервера, `httpserv.New()` создаёт конфигурацию по умолчанию:
- ip: 127.0.0.1
- порт: 8080
- middleware не задан
- пустая карта маршрутизации

Запуск сервера осуществляется через метод `ServerConfig.Run()`.
