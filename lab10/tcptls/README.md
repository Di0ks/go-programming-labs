# TCP-сервер с TLS

TCP-сервер, который обслуживает соединения параллельно, читает данные клиента, выводит сообщение в лог и отвечает числом принятых байт. При завершении процесса закрывает listener и активные подключения.

## Сертификаты и TLS

`StartServer(addr, certPath, keyPath)` загружает сертификат и соответствующий приватный ключ из PEM-файлов через `tls.LoadX509KeyPair`. Сертификат предъявляется клиентам как сертификат сервера. Сервер также добавляет сертификат из `certPath` в пул доверенных CA и включает `tls.RequireAndVerifyClientCert`: клиент обязан предъявить сертификат, который сервер может проверить этим пулом.

В демонстрационном запуске из `lab10/main.go` передаются `certs/certificate.pem` и `certs/privatekey.pem`; сертификат используется и для сервера, и как доверенный клиентский сертификат.

TLS защищает транспорт и проверяет сертификаты во время handshake.
