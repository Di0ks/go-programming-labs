# TCP TLS-клиент

Клиент для сервера из `lab10/tcptls`. `RunClient(addr, certPath, keyPath)` загружает клиентский сертификат с приватным ключом, устанавливает TLS-соединение, отправляет введённое сообщение и сверяет число отправленных байт с ответом сервера.

## Проверка сертификатов и взаимная аутентификация

Клиент предъявляет свой сертификат серверу. Сервер настроен требовать и проверять клиентский сертификат (`tls.RequireAndVerifyClientCert`), поэтому соединение проходит взаимную аутентификацию.

Для проверки сервера клиент добавляет сертификат из `certPath` в пул доверия. В callback `VerifyConnection` он проверяет наличие сертификата сервера, совпадение `CommonName` с доверенным сертификатом и цепочку сертификатов с назначением `ServerAuth`. В текущем включён `InsecureSkipVerify`, так как стандартная проверка имени отключена и заменена этой пользовательской проверкой; проверка имени хоста отдельно не выполняется.

В демонстрации `lab10/main.go` клиенту передаются те же `certs/certificate.pem` и `certs/privatekey.pem`, которые использует сервер.
