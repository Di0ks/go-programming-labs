# REST API Client

Интерактивный консольный клиент для `lab10/restapi`. Учётные записи проверяются сервером.

## Сессии и защита запросов

- Команды `login` и `reg` отправляют email/пароль или профиль пользователя на сервер.
- После входа клиент принимает HTTP-cookie сессии в отдельный cookie jar. Cookie jar и роль хранятся в памяти процесса. Несколько открытых сессий можно переключать командами `sessions` и `switch <email>`.
- Клиент запрашивает CSRF-токен у `GET /auth/csrf`. Для изменяющих запросов и выхода он передаёт его в `X-CSRF-Token`, при этом cookie сессии отправляется автоматически.
- `logout` вызывает `POST /auth/logout` на сервере и удаляет сессию клиента.

Клиент поддерживает просмотр списка и отдельной записи, фильтрацию и пагинацию. Команды `add`, `edit` и `del`, а также `info` для диагностики сервера доступны администраторам. Проверка прав на сервере остаётся обязательной и не зависит от ограничений интерфейса клиента.

## Запуск

Это отдельный Go-модуль. Для запуска из его каталога (без workspace):

```bash
go run .
```

При запуске клиент запрашивает адрес REST API. По умолчанию используется `http://127.0.0.1:8080`.
